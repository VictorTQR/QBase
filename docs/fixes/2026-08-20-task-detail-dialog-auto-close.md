# 修复：任务中心详情对话框打开后自动关闭

- 日期：2026-08-20
- 影响页面：`/tasks` 任务中心（`app/ui/pages/tasks.py`）
- 现象：点击任务"详情"后对话框弹出，最多 5 秒内自动消失，无法查看任务详情

## 根因

两个机制互相冲突：

1. **对话框挂载位置错误**：原代码在"详情"按钮的点击处理器内现场创建 `ui.dialog()`。NiceGUI 3.16 的事件处理器在其触发元素的父插槽中执行（源码 `events.py` `handle_event`："The handler is called within the context of the parent slot of the sender"），因此对话框被挂到了任务列表容器 `container` 内部。
2. **定时刷新销毁对话框**：页面底部的 `ui.timer(5.0, load_tasks)` 每 5 秒重建任务列表，第一步即 `container.clear()`，把挂在容器内的对话框元素连同列表一起销毁。

附带问题：每次点击都会新建一个对话框且从不回收，存在元素泄漏。

## 修复

- 详情对话框提升到页面层级、只创建一次（位于 `container` 之外），定时刷新不再波及
- 新增 `show_detail(task)`：每次打开时 `detail_card.clear()` 后按当前任务重建卡片内容（类型/状态/时间/输出路径/命令/参数/错误信息），再 `dialog.open()`
- `make_detail_handler` 简化为：查库取任务 → 调 `show_detail`；对话框复用同一个实例，消除泄漏

## 经验

- NiceGUI 中**在事件处理器内创建的元素会挂到触发元素的父插槽**，若页面存在 `定时刷新 + 容器 clear()` 模式，对话框/弹出层必须定义在会被 clear 的容器之外（页面层级），或刷新期间暂停定时器
- 对话框的惯用模式：页面层级 `with ui.dialog()` 定义一次 + 内容容器按需 clear/rebuild，而不是每次点击新建

## 验证

1. 打开知识库 → 任务中心 → 点任意任务"详情"，对话框弹出
2. 保持打开超过 10 秒（跨过至少两次自动刷新），对话框不再自动消失
3. 关闭后点另一条任务"详情"，内容正确切换
4. 失败任务"详情"/"重试"均正常
