**状态**: 📋 待实施

**设计目标**: 优化解析管理和向量索引的用户体验

---

## 1. 设计背景与目标

### 1.1 问题分析

当前实现存在以下问题：
- 解析任务和向量索引分离在两个标签页中，用户需要切换查看同一文件的状态
- 左侧导航栏 + 内部标签页的双重导航结构复杂
- 缺乏统一的文件管理视图
- 看板功能缺失
- 双独立状态组合产生16种理论状态，用户认知负担重

### 1.2 设计目标

- ✅ 以文件为中心的统一视图
- ✅ 简化导航结构，采用顶部标签页
- ✅ 提供列表和看板两种视图模式
- ✅ 侧边抽屉展示分块详情
- ✅ 保留所有现有功能（WebSocket、批量操作、统计等）
- ✅ 状态模型简化为4阶段流水线
- ✅ 正交筛选器设计
- ✅ 批量操作优化（复选框、全选）
- ✅ 表头阶段说明

### 3.2 状态模型简化（V2 新增）

#### 原版问题
- 双独立状态（文本解析 × 向量索引）组合产生 16 种理论状态
- 用户需理解"解析完成但未索引"与"解析失败"的区别
- 看板需要 5 列才能展示所有状态组合

#### 改进方案：统一流水线 4 阶段

```
上传 → 解析 → 索引 → 完成
```

**阶段说明**:
| 阶段 | 说明 | 图标 |
|------|------|------|
| 上传 | 文件已添加到系统 | ✓ |
| 解析 | 文本解析中/已完成 | ✓ / ● |
| 索引 | 向量索引中/已完成 | ● / ✓ |
| 完成 | 全部流程完成 | ✓ |

**特殊情况处理**:
- **直接索引的文件**（如已有 Markdown）：解析阶段显示为"跳过"状态（灰色对勾）
- **失败状态**：在当前阶段显示失败图标（✕）

**实现细节**:
- 紧凑横向步骤条（表格中）
- 当前阶段脉冲动画（`animation: pulse 2s infinite`）
- 已完成阶段绿色对勾，失败阶段红色错误标识
- 表头添加说明：`处理阶段 (上传→解析→索引→完成)`

### 3.3 信息架构重组（V2 新增）

#### 原版结构问题
```
Header → Tabs → Filter Chips → Content
                    ↓
            [全部/文档/音频/待解析/解析中/已完成]（重复且混乱）
```

#### 改进结构：正交筛选
```
Header → Tabs → Filter Groups → Content
                    ↓
            类型[全部|文档|音频|视频] × 状态[全部|待处理|处理中|已完成|失败]
```

**筛选器设计**:
- **类型筛选下拉框**：全部 / 文档 / 音频 / 视频
- **状态筛选下拉框**：全部 / 待处理 / 处理中 / 已完成 / 失败
- **搜索框**：实时文件名/路径过滤

## 5. 数据流程设计（V2 更新）

### 5.1 状态模型（V2 更新）

**原版问题**: 16 种组合状态

**改进版**: 4 阶段 + 失败状态

```javascript
// 合并后的文件对象结构（V2）
{
  // 基础信息
  id: Number,
  file_name: String,
  file_path: String,
  file_hash: String,
  file_type: 'pdf'|'md'|'audio'|'other',
  
  // 流水线阶段状态
  pipeline: {
    upload: { status: 'done', time: Date },
    parse: { status: 'done'|'running'|'skipped'|'failed', time: Date, error: String },
    index: { status: 'pending'|'running'|'done'|'failed', time: Date, error: String },
    complete: { status: 'pending'|'done', time: Date }
  },
  
  // 元数据
  page_count: Number,      // 文档页数
  duration: String,        // 音频时长
  chunk_count: Number,
  token_count: Number,
  
  // 计算属性
  current_stage: 'upload'|'parse'|'index'|'complete',
  overall_status: 'pending'|'running'|'completed'|'failed'
}
```

**阶段状态枚举**:
- `pending` - 等待中
- `running` - 进行中
- `done` - 已完成
- `skipped` - 已跳过（灰色）
- `failed` - 失败

### 6.3 批量操作实现

```javascript
// 选中文件管理
const selectedFiles = ref(new Set())
const selectAll = ref(false)

function toggleSelectAll() {
  if (selectAll.value) {
    selectedFiles.value = new Set(allFiles.value.map(f => f.id))
  } else {
    selectedFiles.value.clear()
  }
}

function toggleFileSelection(fileId) {
  if (selectedFiles.value.has(fileId)) {
    selectedFiles.value.delete(fileId)
  } else {
    selectedFiles.value.add(fileId)
  }
  selectAll.value = selectedFiles.value.size === allFiles.value.length
}

// 键盘快捷键
document.addEventListener('keydown', (e) => {
  if ((e.ctrlKey || e.metaKey) && e.key === 'a') {
    e.preventDefault()
    selectAll.value = true
    toggleSelectAll()
  }
})
```
