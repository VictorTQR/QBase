# QBase MVP 设计文档

**日期**: 2026-02-25
**版本**: v0.1
**状态**: 设计中

## 项目概述

QBase 是一个本地知识库管理系统，基于 Vue 3 + Electron 构建。

### 核心定位
- 本地文件夹读取和展示
- 前期不提供编辑功能
- Agent 能力辅助知识管理
- 渐进式迭代开发

### 技术栈
- **前端框架**: Vue 3 (Composition API + `<script setup>`)
- **桌面框架**: Electron
- **状态管理**: Pinia
- **UI组件**: Element Plus + Element-Plus-X
- **构建工具**: Vite
- **测试框架**: Vitest

## v0.1 功能范围

### 必须实现
1. 工作区管理 - 添加/移除本地文件夹
2. 文件夹树导航 - 左侧树形展示
3. Markdown预览 - 中间栏渲染（使用 XMarkdown）
4. 基础全文搜索 - 文件名 + 内容搜索

### 暂不实现
- 编辑功能
- 标签系统
- Agent功能（v0.2实现）
- 历史记录

## 架构设计

### 整体架构
```
┌─────────────────────────────────────────────────────────┐
│                    渲染进程 (Vue 3)                      │
├──────────────────┬──────────────────┬─────────────────────┤
│   左栏           │     中栏         │      右栏            │
│  文件树导航      │   Markdown预览   │    Agent对话面板     │
├──────────────────┴──────────────────┴─────────────────────┤
│                    Pinia 状态管理                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐  │
│  │ workspace   │  │  document   │  │    agent        │  │
│  │   store     │  │   store     │  │    store        │  │
│  └─────────────┘  └─────────────┘  └─────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│                    Electron API (preload)                    │
│  - fileSystem: 读取文件/文件夹                                │
│  - search: 全文搜索                                           │
│  - llm: LLM调用（v0.2预留）                                  │
└─────────────────────────────────────────────────────────────┘
```

### 模块划分

1. **workspace 模块** - 工作区管理
2. **document 模块** - 文档展示
3. **agent 模块** - AI助手（v0.2）
4. **search 模块** - 搜索功能

## UI 布局设计

### 三栏布局
| 栏位 | 宽度 | 功能 | 组件 |
|------|------|------|------|
| 左侧 | 25% | 文件夹树 | el-tree |
| 中间 | 50% | Markdown内容 | XMarkdown |
| 右侧 | 25% | Agent面板（占位） | - |

### 组件结构
```
src/
├── components/
│   ├── Layout/
│   │   ├── MainLayout.vue      # 主布局容器
│   │   ├── Sidebar.vue         # 左侧文件夹树
│   │   ├── ContentPane.vue     # 中间内容区
│   │   └── AgentPanel.vue      # 右侧Agent面板（占位）
│   └── MarkdownViewer.vue      # Markdown渲染组件
└── views/
    └── Home.vue                # 首页
```

## 技术选型细节

### Element-Plus-X 组件使用
| 组件 | 用途 | 阶段 |
|------|------|------|
| XMarkdown | Markdown渲染（代码高亮、公式、mermaid） | v0.1 |
| Bubble | 对话气泡 | v0.2 |
| BubbleList | 气泡列表 | v0.2 |
| Sender | 输入框 | v0.2 |

## 数据持久化

- 使用 pinia-plugin-persistedstate
- 工作区列表持久化到本地

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 文件夹读取失败 | 显示错误提示，跳过 |
| 文件读取失败 | 显示错误消息 |
| Markdown渲染失败 | 降级显示纯文本 |
| 搜索出错 | 显示搜索失败提示 |
