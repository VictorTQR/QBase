# 文档解析管理

**状态**: ✅ 已完成  
**最后更新**: 2026-03-08

## 概述

文档解析管理功能提供了一个独立的全屏界面来管理文档的文本提取任务，支持 PDF 和 Markdown 文件的解析，提供文件管理、看板视图、统计分析、向量索引等功能。

## 功能特性

### 全新 UI/UX 设计

解析管理页面采用全新的三标签页设计，移除了左侧边栏，使用顶部标签页导航：

```
┌─────────────────────────────────────────────────────────────┐
│  ←  解析管理                      [刷新]                  │
├─────────────────────────────────────────────────────────────┤
│  [文件管理] [看板视图] [解析统计]                        │
├─────────────────────────────────────────────────────────────┤
│  正在索引: document.md (3/10)  [████████░░░░] 30%       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  内容区域（文件管理/看板视图/解析统计）                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 顶部标签页导航

- **文件管理**: 表格视图，支持筛选、搜索、批量操作
- **看板视图**: 四列看板，直观展示任务状态流转
- **解析统计**: 统计卡片和状态分布图

### 向量索引进度展示

当正在进行向量索引时，页面顶部会显示进度横幅：

```
正在索引: document.md (3/10)  [████████░░░░] 30%
```

### WebSocket 实时更新

解析管理页面通过 WebSocket 实时接收任务状态更新：

- **自动连接**: 页面加载时自动连接到后端 WebSocket
- **实时同步**: MinerU 和音频任务状态变更立即反映
- **无需刷新**: 任务列表和统计数据自动更新
- **多标签同步**: 多个标签页打开时自动保持同步

**WebSocket 端点**:
- `ws://localhost:8000/ws/tasks/mineru` - MinerU 任务更新
- `ws://localhost:8000/ws/tasks/audio` - 音频任务更新

### 三大功能模块

#### 1. 文件管理（表格视图）

- **正交筛选器**:
  - 类型筛选：文档/音频
  - 状态筛选：待处理/处理中/已完成/失败
  - 搜索框：按文件名或路径搜索

- **批量操作**:
  - 批量解析：启动所有待解析任务
  - 批量索引：索引所有未索引文档
  - 删除：删除选中的文件
  - Ctrl+A 全选快捷键支持

- **四阶段流水线步骤条**:
  - 表头说明：处理阶段 (上传→解析→索引→完成)
  - 可视化展示每个文件的处理进度
  - 支持运行中动画效果

- **文件信息展示**:
  - 文件图标和名称
  - 文件路径（悬停显示完整路径）
  - 分块数量
  - 页数/时长（音频）
  - Token 数（占位）

- **单行操作**:
  - 详情：打开侧边抽屉查看完整信息
  - 重试：失败文件的重试按钮
  - 索引：已解析但未索引文件的索引按钮

#### 2. 看板视图

四列看板设计，直观展示任务状态流转：

**列 1：待处理**
- 显示所有待解析的文件
- "开始"按钮启动解析
- 文件卡片显示文件名和路径

**列 2：处理中**
- 显示正在解析或索引的文件
- 自动更新状态

**列 3：已完成**
- 显示解析和索引都完成的文件
- 绿色左边框高亮
- 显示分块数量标签

**列 4：失败**
- 显示解析失败的文件
- 红色左边框高亮
- 显示错误信息
- "重试"和"删除"按钮

- **卡片交互**:
  - 点击卡片打开详情抽屉
  - 操作按钮使用 .stop 阻止事件冒泡

#### 3. 解析统计

- **解析统计卡片**: 总计、已完成、待解析、失败（4个卡片）
- **向量统计卡片**: 向量分块数、已索引文档数（2个卡片）
- **状态分布**: 可视化彩色进度条
- **快速操作**: 
  - 批量解析待处理文件：启动所有待解析任务
  - 重试失败文件：重置失败任务状态并重新解析
  - 批量索引向量：一键索引所有未索引文档
  - 清空所有向量：清空 LanceDB 中的所有向量数据
- **图例说明**: 各状态颜色和数量说明

### 导出功能

#### 单个文件导出
- 在解析详情抽屉中点击「导出文本」按钮
- 自动下载 TXT 文件，命名为 `原文件名_extracted.txt`

#### 批量导出
- 在解析管理页面顶部点击「导出全部」按钮
- 自动打包所有已完成解析的文件为 ZIP 压缩包
- 文件名格式：`qbase_extracted_时间戳.zip`
- 显示导出进度和结果提示

### 数据存储方案

- **LocalStorage（Pinia 持久化）**：存储解析索引（轻量元数据）
  - 文件路径 → 状态、时间戳、类型等
  - 使用 `useParseStore` 管理

- **IndexedDB（Dexie.js）**：存储提取的大文本内容
  - `extractedTexts` - 提取的文本内容

- **LocalStorage（Pinia 持久化）**：存储向量索引状态
  - `indexedFiles` Set - 已索引文件列表
  - 使用 `useVectorStore` 管理

- **后端 LanceDB**：存储向量数据
  - `document_chunks` 表 - 文档分块和向量
  - 通过 FastAPI `/api/vector/*` 访问

### Store 设计

**useParseStore** 核心功能（未修改）：

```javascript
{
  // 状态
  tasks,           // 任务列表
  currentTask,     // 当前活动任务
  stats,           // 统计数据
  isLoading,       // 加载状态
  
  // 计算属性
  tasksByState,    // 按状态分组的任务
  pendingTasks,    // 待解析文件列表
  runningTasks,    // 解析中文件列表
  doneTasks,       // 已完成文件列表
  failedTasks,     // 失败文件列表
  
  // 方法
  fetchTasks(),    // 获取任务列表
  fetchStats(),    // 获取统计数据
  batchParsePending(), // 批量解析待处理
  retryFailedTasks(), // 重试失败任务
  getTaskResult(), // 获取任务结果
  // ... 更多方法
}
```

## 界面访问

### 入口位置

- **主界面左侧边栏底部** → 「解析管理」按钮
- 点击后跳转到 `/parse-management` 路由
- 页面左上角 ← 按钮返回主页

### 从文件树添加解析

1. 在文件树中右键点击 PDF 或 Markdown 文件
2. 选择「添加到解析」
3. 文件进入解析队列（显示成功提示）
4. 点击「解析管理」按钮进入管理页面
