# 文档解析管理

**状态**: ✅ 已完成  
**最后更新**: 2026-03-03

## 概述

文档解析管理功能提供了一个独立的全屏界面来管理文档的文本提取任务，支持 PDF 和 Markdown 文件的解析，提供队列管理、文档搜索、统计分析、向量索引等功能。

## 功能特性

### 独立全屏页面

解析管理现在是一个独立的全屏页面，通过左侧边栏底部的「解析管理」按钮进入：

```
┌─────────────────────────────────────────────────────────────┐
│  ←  解析管理                      [开始全部] [导出全部]    │
├──────────┬──────────────────────────────────────────────────┤
│          │  ┌─────────────────────────────────────────────┐ │
│  队列    │  │  统计卡片区域                              │ │
│          │  └─────────────────────────────────────────────┘ │
│  已解析  │  ┌─────────────────────────────────────────────┐ │
│          │  │  内容区域（队列/文档/统计）                  │ │
│  统计    │  └─────────────────────────────────────────────┘ │
│          │                                                    │
└──────────┴──────────────────────────────────────────────────┘
```

### 向量索引进度展示

当正在进行向量索引时，页面顶部会显示进度横幅：

```
正在索引: document.md (3/10)  [████████░░░░] 30%
```

### 三大功能模块

#### 1. 队列管理

- **三个标签页**: 解析中 / 待解析 / 失败
- **文件列表**: 显示完整文件路径和元信息
- **操作按钮**: 单个文件解析/重试/移除
- **批量操作**: 
  - 清除已完成：删除所有状态为"已完成"的任务
  - 清空队列：删除所有任务（不可恢复）

#### 2. 已解析文档

- **卡片网格布局**: 更美观的文档展示
- **搜索过滤**: 按文件名关键词搜索
- **状态筛选**: 按解析状态筛选（全部/已完成/解析中/待解析/失败）
- **详情抽屉**: 点击文档卡片打开右侧抽屉查看详情
- **向量索引功能**:
  - 「批量索引向量」按钮：一键索引所有未索引文档
  - 每个文档卡片的「索引向量」按钮
  - 向量状态标签（已索引/未索引）

#### 3. 解析统计

- **解析统计卡片**: 总计、已完成、待解析、失败（4个卡片）
- **向量统计卡片**: 向量分块数、已索引文档数（2个卡片）
- **状态分布**: 可视化彩色进度条
- **快速操作**: 
  - 批量解析待处理文件：启动所有待解析任务
  - 重试失败文件：重置失败任务状态并重新解析
  - 批量索引向量：一键索引所有未索引文档
  - 清空所有向量：清空 LanceDB 中的所有向量数据
- **图例说明**: 各状态颜色和数量说明

### 解析详情抽屉

- 文件信息展示（路径、类型、状态、耗时、大小）
- **文本预览**（已完成的文件）
  - 自动从 IndexedDB 加载完整文本
  - 默认显示前 2000 字符，支持"显示更多"展开
  - 加载状态和空状态提示
- 操作按钮（重新解析、**导出文本**、删除记录）

### 导出功能

#### 单个文件导出
- 在解析详情抽屉中点击「导出文本」按钮
- 自动下载 TXT 文件，命名为 `原文件名_extracted.txt`

#### 批量导出
- 在解析管理页面顶部点击「导出全部」按钮
- 自动打包所有已完成解析的文件为 ZIP 压缩包
- 文件名格式：`qbase_extracted_时间戳.zip`
- 显示导出进度和结果提示

## 技术实现

### 页面结构

```
app/src/
├── views/
│   └── ParseManagement.vue          # 解析管理主页面（含索引进度展示）
├── components/
│   ├── Layout/
│   │   └── ParseSidebar.vue         # 左侧功能导航
│   └── parse/                       # 解析管理组件目录
│       ├── ParseQueueView.vue        # 队列管理视图
│       ├── ParseDocumentsView.vue    # 已解析文档视图（含向量索引）
│       ├── ParseStatsView.vue        # 解析统计视图（含向量统计）
│       ├── FileList.vue              # 通用文件列表
│       └── ParseDetailsDrawer.vue    # 详情抽屉（含文本预览和导出）
├── stores/
│   ├── parse.js                      # useParseStore (已更新)
│   └── vector.js                     # useVectorStore (已增强)
└── utils/
    └── export.js                     # 导出工具模块（新增）
```

### 数据存储方案

- **LocalStorage（Pinia 持久化）**：存储解析索引（轻量元数据）
  - 文件路径 → 状态、时间戳、类型等
  - 使用 `useParseStore` 管理

- **IndexedDB（Dexie.js）**：存储提取的大文本内容
  - `extractedTexts` - 提取的文本内容

- **LocalStorage（Pinia 持久化）**：存储向量索引状态
  - `indexedFiles` Set - 已索引文件列表
  - 使用 `useVectorStore` 管理

- **后端 LanceDB**：存储向量数据
  - `document_chunks` 表 - 文档分块和向量
  - 通过 FastAPI `/api/vector/*` 访问

### 字段统一

**注意**: 代码统一使用 `fileType` 字段，旧数据的 `type` 字段通过计算属性自动兼容转换。

### Store 设计

**useParseStore** 核心功能：

```javascript
{
  // 状态
  parseIndex,      // 解析索引
  queue,           // 解析队列
  activeTask,      // 当前活动任务
  isParsing,       // 是否正在解析
  
  // 计算属性
  stats,           // 统计数据
  pendingFiles,    // 待解析文件列表
  parsingFiles,    // 解析中文件列表
  failedFiles,     // 失败文件列表
  
  // 方法
  loadIndex(),     // 加载索引
  addFile(),       // 添加文件到解析
  startParse(),    // 开始单个解析
  startParseBatch(), // 批量解析
  retryFailed(),   // 重试失败
  reparse(),       // 重新解析
  removeFile(),    // 删除记录
  getExtractedText(), // 获取单个文件提取的文本
  getAllCompletedTexts(), // 获取所有已完成文件的文本（新增）
  getCompletedFiles(), // 获取所有已完成文件列表（新增）
}
```

## 界面访问

### 入口位置

- **主界面左侧边栏底部** → 「解析管理」按钮
- 点击后跳转到 `/parse-management` 路由
- 页面左上角 ← 按钮返回主页

### 从文件树添加解析

1. 在文件树中右键点击 PDF 或 Markdown 文件
2. 选择「添加到解析」
3. 文件进入解析队列（显示成功提示）
4. 点击「解析管理」按钮进入管理页面
