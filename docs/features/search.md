# 搜索增强功能

**状态**: ✅ 已完成
**版本**: v0.3
**完成日期**: 2026-02-25

## 功能概述

搜索增强功能提供了强大的全文搜索能力，支持搜索所有工作区中的 Markdown 文件。

## 功能特性

### 1. 搜索面板
- 独立的弹出式搜索面板
- 支持快捷键 `Ctrl/Cmd + K` 快速打开
- 美观的 UI，带有搜索结果高亮

### 2. 搜索能力
- 支持文件名搜索
- 支持文件内容搜索
- 显示匹配内容的上下文片段
- 大小写不敏感匹配
- 自动防抖搜索（300ms）

### 3. 搜索范围
- 可选择搜索所有工作区
- 可选择搜索特定文件夹
- 记住用户上次选择的搜索范围

### 4. 搜索结果展示
- 文件名高亮显示搜索关键词
- 显示匹配类型标签（文件名/内容）
- 显示内容片段预览
- 显示完整文件路径
- 支持键盘导航

### 5. 快捷键支持
| 快捷键 | 功能 |
|---------|------|
| `Ctrl/Cmd + K` | 打开搜索面板 |
| `↑` / `↓` | 导航搜索结果 |
| `Enter` | 打开选中的文件 |
| `Esc` | 关闭搜索面板 |

## 技术实现

### 数据结构

**搜索结果项**:
```javascript
{
  id: string,           // 文件完整路径
  name: string,         // 文件名
  path: string,         // 文件路径
  type: 'file',
  matchType: 'name' | 'content',  // 匹配类型
  snippet: string,      // 匹配内容的上下文片段
}
```

### 目录结构

```
app/
├── electron/
│   └── main.js              # 搜索 IPC 处理器（增强）
└── src/
    ├── stores/
    │   └── search.js         # 搜索状态管理（新建）
    └── components/
        ├── SearchPanel.vue    # 搜索面板（新建）
        └── Layout/
            └── MainLayout.vue  # 集成搜索按钮
```

### Store 设计

**Search Store (`app/src/stores/search.js`):

- `query`: 搜索关键词
- `results`: 搜索结果列表
- `isLoading`: 搜索加载状态
- `isPanelOpen`: 搜索面板显示状态
- `searchScope`: 搜索范围
- `selectedIndex`: 选中结果索引

**主要方法**:
- `openPanel()`: 打开搜索面板
- `closePanel()`: 关闭搜索面板
- `performSearch()`: 执行搜索
- `selectPreviousResult()`: 选择上一个结果
- `selectNextResult()`: 选择下一个结果
- `getSelectedResult()`: 获取当前选中的结果

### 后端增强

**Electron IPC (`app/electron/main.js`):

- `search-files`: 搜索文件
  - 参数：folderPath, query
  - 返回：成功状态和结果列表
  - 增强：返回 matchType 和 snippet

### 搜索算法

1. 递归遍历文件夹
2. 匹配文件名（优先）
3. 读取文件内容
4. 提取匹配位置前后各 50 字符作为片段
5. 返回匹配结果

## 使用流程

### 搜索流程

```
用户输入关键词
    ↓
防抖延迟 (300ms)
    ↓
根据搜索范围选择文件夹
    ↓
调用 Electron search-files
    ↓
递归搜索所有 .md 文件
    ↓
匹配文件名或内容
    ↓
提取内容片段
    ↓
返回搜索结果
    ↓
前端渲染结果列表
    ↓
高亮匹配关键词
    ↓
用户选择结果
    ↓
打开对应文件
```
