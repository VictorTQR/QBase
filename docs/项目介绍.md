# QBase 项目介绍

> 本地知识库管理系统 —— 用 AI 赋能个人知识管理

---

## 项目概述

### 项目定位

QBase 是一款本地优先的知识库管理系统，旨在帮助用户高效管理和利用本地存储的文档和音视频资料。通过 AI 能力辅助，让知识检索、理解和记忆变得更加智能。

### 核心价值主张

| 价值 | 说明 |
|------|------|
| **本地优先** | 数据完全存储在本地，隐私安全，无需担心云端泄露 |
| **多格式支持** | Markdown、PDF、音视频一应俱全 |
| **AI 赋能** | 智能闪卡、思维导图、摘要生成，辅助知识内化 |
| **向量搜索** | 语义检索 + 全文搜索混合，精准找到相关内容 |
| **渐进式** | 小步迭代，持续演进，保持简洁 |

### 目标用户

- 研究人员：管理论文、笔记，快速检索相关内容
- 学生：制作闪卡，生成摘要，高效复习
- 知识工作者：整理文档资料，构建个人知识库

## 主要功能

### 文档管理

- ✅ **本地文件夹读取** — 直接访问已有文件，无需导入
- ✅ **文件树导航** — 清晰的层次结构浏览
- ✅ **Markdown 预览** — 代码高亮、数学公式、Mermaid 图表
- ✅ **PDF 查看** — 翻页、缩放、文本选择
- ✅ **音视频播放** — 支持 MP3、MP4、WebM 等主流格式

### AI 智能助手

- ✅ **多轮对话** — 基于文档内容的智能问答
- ✅ **流式响应** — 实时显示 AI 思考过程
- ✅ **多会话管理** — 支持创建、切换、重命名对话
- ✅ **闪卡生成** — 自动生成记忆卡片，支持翻转查看
- ✅ **思维导图** — 一键生成文档结构图
- ✅ **智能摘要** — 提取核心内容

### 搜索与检索

- ✅ **全文搜索** — 快速定位关键词
- ✅ **向量搜索** — 基于语义的相似内容检索
- ✅ **混合搜索** — 结合全文和语义，结果更精准
- ✅ **结果片段** — 直接显示匹配内容上下文

### 文档解析

- ✅ **PDF 文本提取** — 本地提取 + MinerU 云端增强
- ✅ **音频转录** — 硅基流动 ASR，支持大文件分块
- ✅ **向量化索引** — 自动分块、嵌入、存储
- ✅ **解析管理** — 队列管理、状态追踪、批量操作
- ✅ **实时更新** — WebSocket 推送任务进度

## 技术亮点

### 1. 混合存储方案

采用多存储策略，兼顾性能与容量：

| 数据类型 | 存储方案 | 理由 |
|----------|----------|------|
| 配置状态 | LocalStorage | 小量、频繁访问 |
| 提取文本 | IndexedDB | 大量文本、结构化查询 |
| 向量数据 | LanceDB | 专业向量库、高效检索 |
| 任务记录 | SQLite | 后端任务队列 |

### 2. 插件化架构

预埋统一接口层，支持无缝切换实现：

```javascript
// 向量存储接口
interface VectorStore {
  index(doc: Document): Promise<void>
  search(query: string, limit: number): Promise<Result[]>
}

// 文档处理接口
interface DocumentProcessor {
  process(file: File): Promise<ProcessedResult>
  status(taskId: string): Promise<TaskStatus>
}
```

当前云端 API 实现，后期可切换到本地方案（transformers.js、Ollama）。

### 3. WebSocket 实时更新

后台任务状态实时推送，无需轮询：

```
客户端连接 → WebSocket 保持连接
                       ↓
        后台任务完成 → 广播状态更新
                       ↓
            前端自动更新 UI
```

### 4. 混合搜索策略

结合全文检索和语义相似度：

```javascript
async function hybridSearch(query: string) {
  const [fullText, semantic] = await Promise.all([
    fullTextSearch(query),
    vectorSearch(query)
  ])
  return mergeAndRank(fullText, semantic)
}
```

## 开发指南

### 快速开始

```bash
# 1. 克隆项目
git clone <repo-url>
cd QBase

# 2. 安装前端依赖
cd app
npm install

# 3. 安装后端依赖（需要 uv）
cd ../backend
uv pip install -r requirements.txt

# 4. 启动开发模式
cd app
npm run start  # 同时启动 Vite + Electron
```

### 项目结构

```
QBase/
├── app/                     # Electron 前端应用
│   ├── src/
│   │   ├── components/      # Vue 组件
│   │   ├── stores/          # Pinia 状态管理
│   │   ├── repositories/    # 数据访问抽象层
│   │   ├── views/           # 页面组件
│   │   └── router/          # 路由配置
│   └── electron/            # Electron 主进程
├── backend/                 # FastAPI 后端
│   └── src/
│       ├── api/             # API 路由
│       ├── models/          # 数据模型
│       ├── processors/      # 文档处理器
│       └── vector/          # 向量搜索服务
└── docs/                    # 项目文档
```

### 开发原则

- **奥卡姆剃刀** — 简单方案优先
- **KISS** — 保持代码清晰易懂
- **YAGNI** — 不预不需要的功能
- **中文优先** — 文档、注释使用中文
