## 1. 设计概述

### 1.1 项目定位

QBase 是一个面向个人用户的本地知识库管理系统，提供文档阅读、AI 辅助、知识整理等功能。

### 1.2 设计理念

- **简洁高效**: 减少视觉干扰，聚焦内容本身
- **一致性**: 遵循统一的设计语言和交互模式
- **可访问性**: 确保不同能力用户都能流畅使用
- **性能优先**: 保证界面响应迅速

### 1.3 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue 3 | 3.5.13 | 前端框架 |
| Element Plus | 2.13.2 | UI 组件库 |
| vue-element-plus-x | 1.3.98 | 扩展组件库 |
| Pinia | 3.0.4 | 状态管理 |

## 2. 设计系统

### 2.1 颜色方案

#### 2.1.1 基础色彩

基于 Element Plus CSS 变量系统：

| 用途 | 变量名 | 说明 |
|------|--------|------|
| 主色调 | `--el-color-primary` | 蓝色系，用于按钮、链接等 |
| 成功色 | `--el-color-success` | 绿色系，用于成功状态 |
| 警告色 | `--el-color-warning` | 橙色系，用于警告提示 |
| 危险色 | `--el-color-danger` | 红色系，用于错误状态 |
| 信息色 | `--el-color-info` | 灰色系，用于中性信息 |

#### 2.1.2 背景色层级

| 层级 | 变量名 | 使用场景 |
|------|--------|----------|
| 页面背景 | `--el-bg-color-page` | 整体页面背景 |
| 组件背景 | `--el-bg-color` | 卡片、面板等 |
| 填充色 | `--el-fill-color` | 输入框、悬停状态 |
| 浅填充 | `--el-fill-color-light` | 次要填充 |
| 更浅填充 | `--el-fill-color-lighter` | 最次要填充 |

#### 2.1.3 特殊主题色

| 组件 | 颜色值 | 说明 |
|------|--------|------|
| PDF Viewer | `#525659` | 深色阅读背景 |
| PDF 工具栏 | `#323639` | 深色工具栏 |
| 工作区选择页 | `linear-gradient(135deg, #667eea 0%, #764ba2 100%)` | 紫色渐变背景 |
| 索引横幅 | `#dbeafe` | 蓝色提示背景 |

### 2.2 间距系统

采用 8px 基础单位的间距体系：

| 尺寸 | 值 | 使用场景 |
|------|-----|----------|
| xs | 4px | 紧凑间距 |
| sm | 8px | 小间距 |
| md | 12px | 中等间距 |
| base | 16px | 标准间距 |
| lg | 20px | 大间距 |
| xl | 24px | 超大间距 |
| 2xl | 32px | 特大间距 |

### 2.3 圆角系统

| 尺寸 | 值 | 使用场景 |
|------|-----|----------|
| sm | 4px | 小元素 |
| base | 6px | 标准元素 |
| md | 8px | 中等元素 |
| lg | 12px | 卡片、面板 |
| xl | 16px | 大型组件 |

### 2.4 阴影系统

| 层级 | 值 | 使用场景 |
|------|-----|----------|
| 轻量 | `0 1px 2px 0 rgba(0, 0, 0, 0.05)` | 卡片默认状态 |
| 中等 | `0 4px 6px -1px rgba(0, 0, 0, 0.1)` | 悬停状态 |
| 厚重 | `0 10px 15px -3px rgba(0, 0, 0, 0.1)` | 弹窗、下拉 |

### 2.5 字体系统

#### 2.5.1 字体家族

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

#### 2.5.2 字号层级

| 级别 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| 一级标题 | 18px | 600 | 页面标题 |
| 二级标题 | 16px | 600 | 区块标题 |
| 正文 | 14px | 400 | 主要内容 |
| 辅助文字 | 12px | 400 | 提示、说明 |
| 小字 | 11px | 400 | 标签、状态 |

#### 2.5.3 行高

| 类型 | 行高 |
|------|------|
| 标题 | 1.4 |
| 正文 | 1.6 |
| 紧凑 | 1.2 |

### 2.6 动画系统

| 属性 | 值 | 使用场景 |
|------|-----|----------|
| 过渡时间 | 0.2s | 悬停、激活 |
| 缓动函数 | ease | 标准缓动 |
| 淡入淡出 | fade 0.2s | 元素显示/隐藏 |

## 3. 布局设计

### 3.1 整体布局架构

QBase 采用多页面布局架构，主要包含：

1. 工作区选择页面（单页全屏）
2. 主应用页面（三栏布局）
3. 设置页面（双栏布局）
4. 解析管理页面（双栏布局）

### 3.2 三栏主布局

```
┌─────────────────────────────────────────────────────────────────┐
│  Header (48px)                                                    │
├──────────────┬──────────────────────────────┬────────────────────┤
│  Sidebar     │  Content Pane                │  Agent Panel       │
│  (25%)       │  (flex: 1)                   │  (45%)             │
│              │                              │                    │
└──────────────┴──────────────────────────────┴────────────────────┘
```

#### 3.2.1 Header 规范

- **高度**: 48px
- **背景色**: `var(--el-bg-color)`
- **下边框**: 1px solid `var(--el-border-color)`
- **内容排列**: 左对齐 Logo 和工作区，右对齐搜索和设置

#### 3.2.2 Sidebar 规范

- **宽度**: 25%，最小 200px
- **背景色**: `var(--el-bg-color-page)`
- **右边框**: 1px solid `var(--el-border-color-lighter)`
- **内容**: 文件树、文件列表、操作按钮

#### 3.2.3 Content Pane 规范

- **宽度**: flex: 1（自适应剩余空间）
- **背景色**: `var(--el-bg-color-page)`
- **内容**: 文档查看器（Markdown/PDF/媒体）

#### 3.2.4 Agent Panel 规范

- **宽度**: 45%，最小 450px
- **背景色**: `var(--el-bg-color)`
- **左边框**: 1px solid `var(--el-border-color-lighter)`
- **内容**: AI 聊天、闪卡、思维导图、摘要

### 3.3 双栏布局（设置/解析管理）

```
┌─────────────────────────────────────────────────────────────────┐
│  Header (48px)                                                    │
├──────────────┬───────────────────────────────────────────────────┤
│  Sidebar     │  Content Area                                     │
│  (200px)     │  (flex: 1)                                        │
│              │                                                     │
└──────────────┴───────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│ ← 返回  解析管理                        [刷新]          │

│  文件管理 | 看板视图 | 解析统计                         │
├─────────────────────────────────────────────────────────┤
│  正在索引: filename.md (3/10)  [████████░░] 70%        │
├─────────────────────────────────────────────────────────┤
│                                                           │
│  [看板/文件管理/统计内容区域]                            │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

#### 4.3.2 看板视图

| 列 | 状态 | 说明 |
|----|------|------|
| 待处理 | pending | 等待解析的文件 |
| 处理中 | processing | 正在解析的文件 |
| 已完成 | ready | 解析完成的文件 |
| 失败 | error | 解析失败的文件 |

## 5. 组件设计

### 5.1 布局组件

#### 5.1.1 MainLayout

**文件**: `app/src/components/Layout/MainLayout.vue`

- **用途**: 提供统一的 Header + 内容区域布局
- **Props**: 无
- **Slots**: `default`（内容区域）

#### 5.1.2 Sidebar

**文件**: `app/src/components/Layout/Sidebar.vue`

- **用途**: 文件导航侧边栏
- **宽度**: 25%，最小 200px
- **功能**: 文件树、文件列表切换

#### 5.1.3 ContentPane

**文件**: `app/src/components/Layout/ContentPane.vue`

- **用途**: 文档查看器容器
- **宽度**: flex: 1
- **背景**: `var(--el-bg-color-page)`

#### 5.1.4 AgentPanel

**文件**: `app/src/components/Layout/AgentPanel.vue`

- **用途**: AI 功能面板容器
- **宽度**: 45%，最小 450px
- **功能**: 可收起、面板切换

#### 5.1.5 PanelNavSidebar

**文件**: `app/src/components/Layout/PanelNavSidebar.vue`

- **用途**: 右侧垂直图标导航
- **宽度**: 64px
- **交互**: 悬停显示文字标签

#### 5.1.6 SettingsSidebar

**文件**: `app/src/components/Layout/SettingsSidebar.vue`

- **用途**: 设置页面侧边栏导航
- **宽度**: 200px
- **菜单项**: 图标 + 文字

### 5.2 文档查看器组件

#### 5.2.1 DocumentViewer

**文件**: `app/src/components/DocumentViewer.vue`

- **用途**: 文件类型分发器
- **支持类型**: Markdown、PDF、图片、音视频

#### 5.2.2 MarkdownViewer

**文件**: `app/src/components/MarkdownViewer.vue`

- **用途**: Markdown 文档渲染

#### 5.2.3 PdfViewer

**文件**: `app/src/components/PdfViewer.vue`

- **用途**: PDF 文档查看
- **工具栏**: 翻页、缩放、全屏
- **主题**: 深色阅读背景

#### 5.2.4 MediaViewer

**文件**: `app/src/components/MediaViewer.vue`

- **用途**: 音视频播放
- **支持格式**: MP3、MP4、WebM

### 5.3 AI 功能组件

#### 5.3.1 ChatModule

**文件**: `app/src/components/ChatModule.vue`

- **用途**: AI 聊天界面
- **功能**: 会话列表、消息气泡、流式响应

#### 5.3.2 FlashcardPanel

**文件**: `app/src/components/FlashcardPanel.vue`

- **用途**: 闪卡生成与管理
- **视图**: 生成、列表、学习
- **导航**: 底部标签切换

#### 5.3.3 MindmapGenerator

**文件**: `app/src/components/MindmapGenerator.vue`

- **用途**: 思维导图生成
- **渲染**: SVG

#### 5.3.4 SummaryGenerator

**文件**: `app/src/components/SummaryGenerator.vue`

- **用途**: 文档摘要生成

### 5.4 搜索组件

#### 5.4.1 SearchPanel

**文件**: `app/src/components/SearchPanel.vue`

- **用途**: 全局搜索面板
- **挂载**: 使用 Teleport 挂载到 body
- **快捷键**: Ctrl+K
- **尺寸**: 最大宽度 600px，圆角 12px
- **搜索模式**: 全文、向量、混合

### 5.5 状态标签系统

| 状态 | 类名 | 背景色 | 文字色 |
|------|------|--------|--------|

| 缺失 | `file-status.missing` | 灰色 | 灰色 |

### 5.6 卡片设计规范

#### 5.6.2 看板卡片

- **圆角**: 8px
- **内边距**: 12px
- **背景**: `var(--el-bg-color)`

## 6. 交互设计

### 6.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+K | 打开搜索面板 |
| Esc | 关闭搜索面板/弹窗 |

### 6.2 导航交互

#### 6.2.1 页面导航

- **返回按钮**: 左上角箭头，返回到上一页面
- **工作区切换**: Header 下拉选择器

#### 6.2.2 面板导航

- **Agent Panel**: 垂直图标导航，点击切换功能
- **设置页面**: 侧边栏菜单，点击切换设置项

### 6.3 搜索交互

- **打开**: Ctrl+K 或点击搜索按钮
- **输入**: 实时搜索建议
- **关闭**: Esc 或点击外部区域
- **高亮**: 搜索关键词高亮显示

### 6.4 文件操作

- **选择**: 点击文件加载到查看器
- **刷新**: 手动刷新文件列表
- **解析**: 触发文档解析任务

### 6.5 加载状态

- **指示器**: 旋转加载图标
- **文字**: "加载中..."
- **布局**: 居中显示

### 6.6 错误状态

- **指示器**: 警告图标
- **文字**: 错误信息描述
- **布局**: 居中显示
- **操作**: 提供重试按钮（如适用）

### 6.7 空状态

- **组件**: `<el-empty>`
- **内容**: 图标 + 描述文字
- **操作**: 提供引导操作按钮（如适用）
