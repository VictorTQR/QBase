## 核心设计

### 1. DocumentViewer 模式

根据文件类型自动选择对应的查看器：
- `.md` → MarkdownViewer
- `.pdf` → PdfViewer
- 音频 → MediaViewer (audio)
- 视频 → MediaViewer (video)

### 2. PdfViewer 实现

- 使用 pdfjs-dist 渲染
- 支持翻页（上一页/下一页）
- 支持缩放（0.5x - 3x）
- 预留接口：分页懒加载、文本搜索（后续版本）

### 3. 闪卡数据结构

```javascript
// 闪卡集合
{
  id: string,
  title: string,
  sourceFile: string,
  createdAt: string,
  flashcards: [
    {
      id: string,
      front: string,        // 问题
      back: string,         // 答案
      difficulty: 'easy'|'medium'|'hard',
      mastered: boolean,
      lastReviewed: string|null
    }
  ]
}
```

### 4. 提示词设计

专门的闪卡生成提示词，要求：
- 生成 5-20 张闪卡
- 考察核心概念理解
- 答案简洁准确（2-3 句话）
- JSON 格式输出
