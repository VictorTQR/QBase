# v1.0 后端服务集成实施报告

**版本**: v1.0  
**完成日期**: 2026-03-02  
**状态**: ✅ 已完成

## 概述

本次实施完成了从 Electron IPC 调用到 FastAPI 后端 HTTP 调用的迁移，实现了独立后端模式，并通过策略模式设计为后续切换到一体化模式预留了扩展点。

## 目标

- 将 MinerU API 调用从 Electron 主进程迁移到独立的 FastAPI 后端
- 提供灵活的架构设计，支持独立后端和一体化后端两种模式
- 保持代码的可维护性和可扩展性

**新建文件**:

**修改文件**:
- `app/src/processors/parse/TextExtractor.js` - 重构为使用策略模式

#### 核心设计

```javascript
export class TextExtractor {
  static strategy = new RemoteBackendStrategy()
  
  static setStrategy(strategy) {
    this.strategy = strategy  // 支持动态切换策略
  }
  
  static async extractPdf(filePath, config) {
    return await this.strategy.extractPdf(filePath, config)
  }
}
```

## 架构决策

### 1. 策略模式选择
- **选择**: Strategy 设计模式
- **原因**: 支持灵活切换后端实现，无需修改调用方代码

### 2. API 客户端设计
- **选择**: 封装 hook-fetch，提供类型友好的 API
- **原因**: 统一 API 调用风格，便于测试和 mock

### 3. 本地文件路径支持
- **选择**: 新增 `/parse-local` 端点
- **原因**: Electron 可直接传递文件路径，避免文件重复上传

### 4. 错误处理增强
- **选择**: 优化错误提示，提供后端启动指引
- **原因**: 改善用户体验，便于调试

## 为一体化模式预留的设计

### 未来切换到一体化模式的步骤

当需要切换到一体化模式时，只需：

1. **创建一体化策略**
   ```javascript
   // app/src/processors/parse/EmbeddedBackendStrategy.js
   export class EmbeddedBackendStrategy extends BackendStrategy {
     async extractPdf(filePath, config) {
       // 使用内部端口 :8765
       // 复用 RemoteBackendStrategy 的逻辑
     }
   }
   ```

2. **在应用启动时切换策略**
   ```javascript
   import { TextExtractor } from '@/processors/parse/TextExtractor'
   import { EmbeddedBackendStrategy } from '@/processors/parse/EmbeddedBackendStrategy'
   
   TextExtractor.setStrategy(new EmbeddedBackendStrategy())
   ```

3. **Electron 主进程启动 FastAPI 子进程**
   - 内部端口使用 8765
   - 应用退出时自动清理子进程
