# v0.8 设置功能集成修复

**日期**: 2026-03-02  
**状态**: ✅ 已完成

---

## 问题描述

v0.8 版本的设置页面组件已经开发完成，但存在以下集成问题：

1. **路由缺失** - `router/index.js` 中没有 `/settings` 路由
2. **入口缺失** - `MainLayout.vue` Header 没有设置按钮
3. **旧代码未清理** - `AgentPanel` 和 `PanelHeader` 仍有设置按钮，仍在使用 `LlmConfigDialog`
4. **文件未删除** - `LlmConfigDialog.vue` 文件仍然存在

---

## 修复内容

### 1. 添加 /settings 路由

**文件**: `app/src/router/index.js`

```javascript
const routes = [
  {
    path: '/',
    name: 'home',
    component: () => import('@/views/Home.vue'),
  },
  {
    path: '/settings',
    name: 'settings',
    component: () => import('@/views/Settings.vue'),
  },
]
```

### 2. MainLayout 添加设置按钮

**文件**: `app/src/components/Layout/MainLayout.vue`

- 导入 `Setting` 图标和 `useRouter`
- 在 Header 的 actions 区域添加设置按钮
- 添加 `handleOpenSettings()` 函数，跳转到 `/settings`

### 3. PanelHeader 移除设置按钮

**文件**: `app/src/components/shared/PanelHeader.vue`

- 移除 `Setting` 图标导入
- 移除 settings emit
- 移除设置按钮 UI

### 4. AgentPanel 清理

**文件**: `app/src/components/Layout/AgentPanel.vue`

- 移除 `ref` 导入
- 移除 `LlmConfigDialog` 导入
- 移除 `showConfig` ref
- 移除 `handleSettings` 函数
- 移除 `@settings` 事件监听
- 移除 `<LlmConfigDialog>` 组件

### 5. 删除 LlmConfigDialog.vue

删除文件: `app/src/components/LlmConfigDialog.vue`
