## 概述

## 核心设计

### 1. AiGeneratorPanel 组件

统一的智能生成面板，提供三种生成功能：

**标签页结构**：
- **闪卡** - 闪卡生成功能，可调节数量（5-20）
- **思维导图** - 思维导图生成和 SVG 预览
- **摘要** - 摘要生成和文本预览

**交互流程**：
1. 用户选择生成类型和参数
2. 点击生成按钮
3. 从 DocumentStore 获取当前文档内容
4. 调用 AgentStore 相应生成方法
5. 显示加载状态
6. 预览生成结果
7. 错误时显示错误提示

### 2. Agent Store 扩展

新增三个生成方法：

```javascript
// 生成闪卡
async function generateFlashcards(content, count)

// 生成思维导图
async function generateMindmap(content)

// 生成摘要
async function generateSummary(content)
```

**统一返回格式**：
```javascript
{
  success: boolean,
  data?: object|array|string,
  error?: string
}
```

### 3. 提示词模板设计

#### 思维导图提示词

**要求**：
- 提取文档的核心概念和层级关系
- 生成结构化的思维导图
- 节点包含关键词或短语
- 输出 JSON 格式（title + nodes）

**数据结构**：
```json
{
  "title": "文档标题",
  "nodes": [
    {
      "id": "node1",
      "text": "节点文本",
      "parent": "父节点ID或null",
      "children": ["子节点ID数组"]
    }
  ]
}
```

#### 摘要提示词

**要求**：
- 提取文档的核心内容和关键信息
- 生成结构清晰的摘要
- 控制字数在 300-500 字
- 保持原文的逻辑结构和重点
- 中文输出

**数据结构**：
```
字符串格式的摘要内容
```

### 4. 思维导图预览实现

使用 SVG 实时渲染思维导图：

**节点渲染**：
- 根节点：蓝色边框，浅蓝色背景
- 子节点：绿色边框，浅绿色背景
- 节点尺寸：160×40
- 文本居中对齐

**连线渲染**：
- 使用 SVG `<line>` 元素
- 颜色：#409eff
- 宽度：2px

**布局算法**：
- 预设节点位置（简化实现）
- 支持滚动查看

## 数据流

1. **用户操作**：用户在 AiGeneratorPanel 选择生成类型并点击生成
2. **内容获取**：从 DocumentStore 获取当前打开文档的内容
3. **提示模板**：使用对应的提示模板包装文档内容
4. **LLM 调用**：通过 AgentStore 调用 LLM API
5. **响应解析**：解析 JSON 格式的响应
6. **结果展示**：在面板中预览生成结果

---

## 错误处理

### 错误场景

1. **无文档打开**：
   - 错误提示："请先打开一个 Markdown 文档"
   - 不执行生成操作

2. **LLM 调用失败**：
   - 捕获网络错误、API 错误
   - 显示具体错误信息

3. **响应解析失败**：
   - JSON 解析失败
   - 显示格式错误提示

4. **生成结果为空**：
   - 检查响应内容
   - 提示用户重试
