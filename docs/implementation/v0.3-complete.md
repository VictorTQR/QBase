## 技术决策

### Repository 模式

使用 Repository 模式抽象存储层：

```javascript
// 抽象接口
export class SessionRepository {
  async getAll() { ... }
  async getById(id) { ... }
  async create(session) { ... }
  async update(id, updates) { ... }
  async delete(id) { ... }
}

// localStorage 实现
export class LocalStorageSessionRepository extends SessionRepository {
  // 实现具体存储逻辑
}
```

**优点**:
- 存储实现与业务逻辑解耦
- 后续可轻松切换到文件系统/SQLite
- 便于单元测试

### 数据模型

**Session 结构**:
```javascript
{
  id: string,              // UUID
  title: string,           // 会话标题
  createdAt: string,       // ISO 时间戳
  updatedAt: string,       // ISO 时间戳
  messages: Message[]      // 消息列表
}
```

### 自动命名策略

根据用户第一条消息自动生成会话标题：
- 取前 30 个字符
- 超出时添加 "..."
- 默认标题为 "新对话"

### 相对时间显示

会话列表显示相对时间：
- < 1 分钟："刚刚"
- < 1 小时："X 分钟前"
- < 1 天："X 小时前"
- 更早：显示日期

### 测试连接功能

在 LLM 配置对话框中添加「测试连接」按钮：
- 调用 `testConnection()` 发送简单的测试请求
- 临时使用表单配置，测试后恢复原始配置
- 使用 ElMessage 显示成功/失败结果
- 支持 loading 状态

### 多轮对话上下文

修改 `sendMessage()` 函数：
- 在添加新消息前获取历史消息
- 构建完整的 messages 数组：`[system, ...历史消息, 当前用户消息]`
- AI 可以记住之前的对话内容

### 手动刷新功能

在工作区侧边栏添加刷新按钮：
- 使用 Element Plus Refresh 图标
- 支持 loading 状态防止重复点击
- 点击按钮调用 `refreshTree()` 重新加载文件树
- 文件夹监听功能暂缓实现（遵循渐进式开发原则）

### 清空消息标题重置

修改 `clearMessages()` 函数：
- 清空消息时同时重置会话标题为「新对话」
- 更新 `_saveCurrentSession()` 以保存标题变化

### 搜索增强功能

#### 后端增强 (`app/electron/main.js`)

增强现有 `search-files` IPC 处理器：
- 添加 `matchType` 字段：`'name'`（文件名匹配）或 `'content'`（内容匹配）
- 添加 `snippet` 字段：提取匹配内容前后各 50 个字符的上下文片段
- 支持多文件夹并发搜索

#### 搜索 Store (`app/src/stores/search.js`)

使用 Pinia 创建搜索状态管理：
- 状态：query, results, isLoading, error, isPanelOpen, searchScope, selectedIndex
- 方法：openPanel(), closePanel(), performSearch(), selectPreviousResult(), selectNextResult()
- 持久化：记住用户上次选择的搜索范围

#### 搜索面板组件 (`app/src/components/SearchPanel.vue`)

独立的弹出式搜索面板：
- 使用 Teleport 渲染到 body
- 防抖搜索（300ms）
- 搜索范围选择器
- 结果高亮显示
- 键盘导航支持

#### 快捷键支持

| 快捷键 | 功能 |
|---------|------|
| `Ctrl/Cmd + K` | 打开搜索面板 |
| `↑` / `↓` | 导航搜索结果 |
| `Enter` | 打开选中的文件 |
| `Esc` | 关闭搜索面板 |

### 后续扩展路径

切换到文件系统或 SQLite 只需：
1. 创建新的 Repository 实现（如 `FileSessionRepository.js`）
2. 修改 `agent.js` 中初始化 repository 的那一行
3. 无需改动任何其他代码

## 风险与注意事项

1. **localStorage 容量限制**: 约 5-10MB，大量消息可能超出限制（后续版本迁移到文件系统）
2. **数据迁移**: 现有用户的旧消息未做迁移（v0.2 消息未持久化，影响较小）
3. **性能**: 消息量大时考虑分页加载（v0.4+）
