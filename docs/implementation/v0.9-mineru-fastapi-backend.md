# v0.9 MinerU FastAPI 后端实施报告

**版本**: v0.9  
**完成日期**: 2026-03-02  
**状态**: ✅ 已完成

## 概述

本次实施在 backend 目录下构建了完整的 FastAPI 后端服务，实现了 MinerU 文档解析功能。

## 目标

- 将 MinerU API 调用从 Electron 主进程迁移到独立的 Python 后端
- 提供 RESTful API 接口供前端调用
- 支持任务状态管理和异步轮询
- 为后续功能扩展（向量化、搜索增强）奠定基础

## 实现内容

### 1. 项目结构

```
backend/
├── pyproject.toml          # Python 项目配置（uv）
├── .env.example            # 环境变量示例
├── main.py                 # FastAPI 主应用入口
└── src/
    ├── config.py           # 配置管理（pydantic-settings）
    ├── models/
    │   └── schemas.py      # Pydantic 数据模型
    ├── mineru/
    │   ├── client.py       # MinerU API 客户端封装
    │   └── task_manager.py # 任务状态管理（内存存储）
    ├── api/
    │   └── mineru.py       # FastAPI 路由定义
    └── utils/
        └── zip_handler.py  # ZIP 解压处理
```

### 3. API 端点

| 端点 | 方法 | 功能 | 状态 |
|------|------|------|------|
| `/health` | GET | 健康检查 | ✅ |
| `/api/mineru/parse` | POST | 提交文档解析任务 | ✅ |
| `/api/mineru/tasks/{task_id}` | GET | 查询任务状态 | ✅ |
| `/api/mineru/tasks/{task_id}/result` | GET | 获取解析结果（Markdown） | ✅ |
| `/api/mineru/tasks/{task_id}/download` | GET | 下载原始 ZIP | ✅ |

### 4. 核心模块

#### MinerU 客户端 (`mineru/client.py`)
- 批量申请上传链接 (`POST /api/v4/file-urls/batch`)
- 文件上传 (PUT)
- 批量查询任务结果 (`GET /api/v4/extract-results/batch/{batch_id}`)
- 下载结果 ZIP

#### 任务管理器 (`mineru/task_manager.py`)
- 纯内存任务状态存储
- 异步轮询任务状态更新
- 任务 CRUD 操作

#### ZIP 处理器 (`utils/zip_handler.py`)
- 从 ZIP 字节流提取 Markdown 内容
- 自动查找第一个 .md 文件

### 5. 配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|

## 架构决策

### 1. 任务存储方案
- **选择**: 纯内存存储（第一版）
- **原因**: 简单快速，后续可扩展到 SQLite/Redis

### 2. 文件处理方式
- **选择**: 批量上传方式
- **原因**: 符合 MinerU API 设计，避免需要公网可访问的文件服务

### 3. 任务状态管理
- **选择**: 仅轮询方式
- **原因**: 简单易实现，回调方式需要公网地址

### 4. 结果处理方式
- **选择**: 后端代理下载
- **原因**: 统一管理解析结果，前端更简洁

## 前端集成策略

- 保留 Electron IPC 方式（向后兼容）
- 新增 HTTP 客户端，两者可配置切换
- 逐步迁移到 FastAPI 后端
