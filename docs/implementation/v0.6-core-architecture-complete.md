## 三、修改文件

### 3.1 app/electron/preload.js

**新增 API 命名空间**:
- `mineru.*` - MinerU 相关 API
- `siliconflow.*` - SiliconFlow 相关 API

### 3.2 app/electron/main.js

**新增 IPC 处理器**:
- `mineru:create-upload-urls` - 申请上传链接
- `mineru:upload-file` - 上传文件
- `mineru:submit-task` - 提交解析任务
- `mineru:poll-task-status` - 轮询任务状态
- `mineru:download-result` - 下载结果
- `mineru:extract-pdf` - 一站式 PDF 解析
- `siliconflow:create-embedding` - 创建 Embedding

**新增辅助函数**:
- `makeRequest()` - HTTP 请求封装
- `uploadFile()` - PUT 文件上传
- `downloadFile()` - 文件下载

### 3.3 app/src/stores/agent.js

**配置扩展**:
```javascript
llmConfig: {
  // ... 现有配置 ...
  mineru: {
    apiKey: '',
    baseUrl: 'https://mineru.net'
  },
  siliconflow: {
    apiKey: '',
    baseUrl: 'https://api.siliconflow.cn',
    embeddingModel: 'BAAI/bge-large-zh-v1.5',
    asrModel: 'FunAudioLLM/SenseVoiceSmall'
  }
}
```

### 3.4 app/src/components/LlmConfigDialog.vue

**UI 扩展**:
- 新增 Tab 组件，3 个标签页：
  - LLM（原有）
  - MinerU (PDF)
  - SiliconFlow
- 配置表单支持深度合并
