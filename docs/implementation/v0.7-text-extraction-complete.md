## 一、概述

本次实施完成了 v0.7 版本的核心功能：**文本提取**，实现了 Markdown 和 PDF 文件的本地文本提取，并集成到解析管理工作流中。

### 功能亮点

- ✅ Markdown 文本提取（去除 frontmatter）
- ✅ PDF 本地文本提取（基于 pdfjs-dist）
- ✅ 混合策略：优先本地，可选云端 MinerU 降级
- ✅ 解析状态管理
- ✅ IndexedDB 存储提取结果
- ✅ 完整 UI 集成

---

## 二、实现内容

### 2.1 TextExtractor 核心类

**文件**: `app/src/processors/parse/TextExtractor.js`

**功能**:
- `extract()` - 统一入口方法
- `extractMarkdown()` - Markdown 文本提取
- `extractPdf()` - PDF 文本提取（智能选择本地/云端）
- `extractPdfLocal()` - 本地 PDF 提取
- `extractWithMinerU()` - 云端 MinerU 提取

### 2.2 ParseStore 扩展

**文件**: `app/src/stores/parse.js`

**新增方法**:
- `startParse(filePath, fileType)` - 开始单个文件解析
- `startParseBatch(fileItems)` - 批量解析
- `getExtractedText(filePath)` - 获取提取的文本

### 2.3 UI 集成

**修改的文件**:
1. `Sidebar.vue` - 添加右键菜单"添加到解析"
2. `ParseManager.vue` - 实现批量解析功能
3. `ParseStats.vue` - 添加 loading 状态
4. `ParseDetails.vue` - 添加提取文本预览

## 三、技术架构

### 3.1 混合策略

```
用户触发解析
    ↓
TextExtractor.extract()
    ↓
判断文件类型
    ↓
Markdown: 本地提取
PDF: 优先本地 → 失败则尝试云端（如果配置）
    ↓
保存到 IndexedDB
    ↓
更新解析索引
    ↓
更新 UI 状态
```

### 3.2 数据存储

**IndexedDB 表结构**:
```javascript
{
  filePath: String (primary key),
  text: String,
  fileType: String,
  extractedBy: 'local' | 'mineru',
  extractedAt: Date,
  pageCount?: Number,  // PDF 专用
  wordCount?: Number
}
```

## 五、使用说明

### 5.1 添加文件到解析

1. 在文件树中右键点击 Markdown 或 PDF 文件
2. 选择"添加到解析"
3. 自动跳转到解析管理标签页

### 5.2 解析文件

1. 在解析管理中查看待解析文件
2. 点击"批量解析"解析所有待解析文件
3. 或点击单个文件的"重新解析"

### 5.3 查看结果

1. 在解析管理中选择已完成的文件
2. 在详情面板查看提取的文本预览
3. 查看字数、页数等元数据
