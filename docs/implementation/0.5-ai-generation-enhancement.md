## 技术架构

### 数据流

1. **用户输入**：用户在 AiGeneratorPanel 中选择生成类型并点击生成按钮
2. **内容获取**：从 DocumentStore 获取当前打开文档的内容
3. **LLM 调用**：通过 AgentStore 调用相应的生成方法，使用合适的提示模板
4. **结果处理**：解析 LLM 响应，转换为相应的数据结构
5. **结果展示**：在界面上预览生成结果

### 数据结构

#### 思维导图数据结构

```json
{
  "title": "文档标题",
  "nodes": [
    {
      "id": "node1",
      "text": "主主题",
      "parent": null,
      "children": ["node2", "node3"]
    },
    {
      "id": "node2",
      "text": "子主题1",
      "parent": "node1",
      "children": []
    }
  ]
}
```

#### 摘要数据结构

```
字符串格式的摘要内容，包含文档的核心观点和结论
```

## 测试计划

### 功能测试

1. **闪卡生成**：验证生成的闪卡数量和质量
2. **思维导图生成**：验证生成的思维导图结构和内容
3. **摘要生成**：验证生成的摘要是否准确反映文档内容
4. **错误处理**：测试无文档时的错误提示
5. **加载状态**：测试生成过程中的加载状态显示

### 性能测试

1. **响应时间**：测试不同长度文档的生成响应时间
2. **内存使用**：监控生成过程中的内存使用情况
3. **稳定性**：测试连续多次生成的稳定性

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| LLM 响应格式不一致 | 解析失败 | 增加响应格式验证和错误处理 |
| 生成结果质量不佳 | 用户体验差 | 优化提示模板，提供清晰的生成指南 |
| 大文档处理性能 | 响应缓慢 | 考虑添加文档内容长度限制或分段处理 |

## 预期成果

1. **统一的智能生成界面**：整合闪卡、思维导图、摘要生成功能
2. **高质量的生成结果**：基于 LLM 的智能内容生成
3. **良好的用户体验**：流畅的生成流程和结果预览
4. **稳定的性能**：在合理时间内完成生成任务

## 后续扩展可能性

1. **更多生成类型**：添加大纲生成、问题生成等功能
2. **自定义模板**：允许用户自定义生成提示模板
3. **导出功能**：支持将生成结果导出为不同格式
4. **多语言支持**：扩展到多语言文档的生成
