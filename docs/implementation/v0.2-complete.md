## 技术决策

### 流式请求处理

使用原生 `fetch` API 处理 SSE：

- 无需额外依赖
- 兼容 OpenAI、Ollama 等
- 代码简洁可控

### 消息 ID 生成

使用 Web Crypto API 生成 UUID v4：

- 浏览器原生支持
- 无需安装依赖
- 保证唯一性

### LLM 配置持久化

使用 pinia-plugin-persistedstate：

- 自动保存到 localStorage
- 页面刷新后配置保留

## Bug 修复

### 消息 ID 重复问题

**问题**: 快速连续添加消息时，`Date.now()` 可能生成相同 ID

**修复**: 使用 UUID v4 替代时间戳

**详情**: [Bug 修复记录](../bugs/2026-02-25-message-id-duplicate.md)
