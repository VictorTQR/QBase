## 技术决策

### UI 组件库选择

选择 Element Plus + Element-Plus-X 组合：

- Element Plus: 成熟的 Vue 3 组件库
- Element-Plus-X: AI 体验组件，包含 XMarkdown、Bubble 等

### 状态管理

使用 Pinia + Composition API：

- 类型推断友好
- 开发体验好
- 支持持久化插件

### 文件系统

通过 Electron preload 暴露有限 API：

- 安全性：限制渲染进程权限
- 可维护性：统一 API 入口
